## 🛠️ Tech Stack

* **Framework**: React 18
* **Build Tool**: Vite
* **Routing**: React Router DOM v6
* **Styling**: Tailwind CSS
* **Icons**: Lucide React
* **Maps**: Leaflet & OpenStreetMap
* **Persistence**: Web Storage API (LocalStorage)
